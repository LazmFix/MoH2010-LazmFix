# Development notes (Russian)

> Working notes from making the fix, in Russian. Some features described here (mouse polling rate meter, info overlay, calibration hotkeys, Ctrl+End / Ctrl+PgUp hotkeys) were removed in 0.9.0 to keep the release small. The user-facing description is in the main README.

# MoH 2010 PC Fix

Фиксы для **Medal of Honor (2010), одиночная игра** (Steam, AppID 47790, `Binaries\moh.exe` 1.0.4.0,
32 бит, Unreal Engine 3, DirectX 9, SecuROM). Мультиплеер — отдельная игра, её фикс не трогает.

## Почему игра не запускалась

Игра висит на сплэш-экране вечно (окно `SplashScreen`, процесс жив, ничего не происходит). Снимок стеков
(`logs\hang-stacks-1.txt`, `logs\hang-main-thread.txt`) показал главный поток здесь:

```text
ntdll!NtReadFile                      <- блокирующее чтение 8 байт, handle 0x121c
KERNELBASE!ReadFile
<код SecuROM>                         <- перехват CreateFileW в таблице импорта DINPUT8.dll
DINPUT8!DIHid_GetDevInfo              <- DirectInput открывает HID-устройство
DINPUT8!DIHid_BuildHidList
DINPUT8!DirectInput8Create            <- UE3 создаёт DirectInput
```

SecuROM подменяет импорты `CreateFileW`/`ReadFile` у `DINPUT8.dll` (и других модулей) и после каждого
открытия файла читает из него 8 байт обычным блокирующим `ReadFile`. DirectInput при старте открывает
**все** HID-коллекции. Коллекция, которая никогда не шлёт input-репортов, делает это чтение вечным.
Здесь это `\\?\hid#vid_1532&pid_0099&mi_03` — служебный интерфейс мыши **Razer Basilisk V3**
(VID 1532 = Razer). Отсюда и жалобы «не запускается с Razer Synapse» в Steam: дело не в Synapse, а в
самом интерфейсе мыши.

Проверка вживую: `CancelSynchronousIo` на зависший поток — игра сразу пошла дальше (застряла ещё раз в
`EnumDevices` на том же устройстве, после второго сброса дошла до интро EA).

SecuROM перехватывает ещё и `GetProcAddress` (отдаёт адрес своего перехвата вместо `CreateFileW`), поэтому
фикс берёт настоящую функцию прямо из таблицы экспорта `kernelbase.dll`.

**Проверено 2026-11-04:** с фиксом игра проходит сплэш за 17 с (без него — вечное зависание).

## Что делает фикс

`dinput8.dll` — прокси рядом с `moh.exe` (игра импортирует `DINPUT8.dll`, локальная копия грузится вместо
системной; файлы игры не меняются).

- **Запуск.** На время вызовов DirectInput, которые строят список устройств (`DirectInput8Create`,
  `EnumDevices`, `CreateDevice`, `FindDevice`, `GetDeviceStatus`, `Acquire`…), импорт `CreateFileW`/`A`
  системного `dinput8.dll` указывает на маленький шим: пути `\\?\hid#…` открываются настоящей
  `KernelBase!CreateFileW` мимо SecuROM, всё остальное идёт в перехват SecuROM как обычно. После вызова
  исходное значение возвращается на место. Если перехвата нет — ничего не меняется.
- **Мышь.** UE3 читает мышь через DirectInput — это уже «сырые» отсчёты: без ускорения и скорости
  указателя Windows, на полной частоте опроса (DirectInput сам суммирует все репорты между кадрами).
  Фикс оборачивает системную мышь игры и:
  - умножает отсчёты на **чувствительность X / Y** (дробные остатки переносятся, ничего не теряется;
    1.000 = без изменений);
  - пока открыто меню ReShade — обнуляет движение и кнопки (камера не крутится, оружие не стреляет);
  - **меряет частоту опроса** второй буферизованной DirectInput-мышью в процессе игры (номер
    последовательности на каждый репорт → медиана интервалов);
  - пишет в лог, как игра настроила мышь (формат, cooperative level, режим чтения).
- **ReShade-аддон** `MoH2010.PCFix.addon32`: панель (Home → Add-ons → MoH 2010 PC Fix) как в GTA SA DE /
  CoD4: чувствительность X/Y, вкл/выкл, «Save to ini», статус фикса запуска, частота опроса, отсчёты;
  окно информации поверх игры (Гц, FPS, время кадра, репорты/кадр).
  Хоткеи: **Ctrl+End** — множители вкл/выкл (A/B-сравнение, сохраняется), **Ctrl+Insert** — окно информации.
- **Экран (раздел «Display and game settings» в панели).**
  - *Borderless fullscreen*: аддон в событии ReShade `create_swapchain` превращает полноэкранный режим
    игры в оконный, ядро делает окно без рамки на весь монитор (на игровом потоке, через сабкласс окна).
    Частота — частота рабочего стола (240 Гц), Alt+Tab мгновенный.
  - *Exclusive fullscreen: highest refresh rate*: если borderless выключен, игре подставляется
    максимальная частота монитора для её разрешения (иначе D3D9 берёт частоту по умолчанию).
  - Настройки игры из `MOHAEngine.ini` — те же ключи, что пишет меню «Видео» игры: разрешение, «В окне»,
    верт. синхронизация; плюс лимит FPS (`bSmoothFrameRate`/`MaxSmoothedFrameRate`) и анизотропия
    (`MaxAnisotropy`), которых в меню нет. Работает в обе стороны: панель перечитывает ini раз в секунду
    (видит «Сохранить» в меню игры), изменения из панели игра применит при следующем запуске (панель
    пишет об этом). Разрешение/окно/vsync в меню игры по-прежнему применяются сразу.
  - *Skip intro videos*: переименовывает `MOHAGame\CookedMovies\MOHA_Legal_ID_Only[_RUS].vp6` в
    `*.vp6.skip`; без них игра сразу идёт на экран загрузки и в меню (проверено: ~20 с от запуска).
- **Настройки игры** (`Documents\EA Games\Medal of Honor\Config`, кодировка файлов сохраняется):
  - `MOHAInput.ini` `bEnableMouseSmoothing=false` — сглаживание мыши UE3 выключено;
  - `MOHAEngine.ini` `bSmoothFrameRate=FALSE` — без лимита FPS (было 62; в меню проверено 208+ FPS).
- **Максимальная графика** — `tools\max-graphics.ps1`. Определение железа игры ломается на современных
  картах (замер GPU = 0 мс, VRAM 3 ГБ) и записывает RTX 4080 SUPER в «Minspec» (`CompatLevelGPU=1`): без
  динамических теней и глубины резкости, анизотропия 1x, декали не рисуются. Скрипт ставит пресет игры
  «High end» (`BaseEngine.ini` + `DefaultCompat.ini [AppCompatBucket3]`), анизотропию 16x, тени 2048,
  `Distortion`, и `CompatLevelGPU/Composite=3`, чтобы «Восстан.» в меню не откатывал в минимум.

## Чувствительность мыши (как в CoD4 / MW Remastered)

Панель → Mouse → Sensitivity, режим **CoD4 / MW Remastered scale**: вводите то же число, что в MWR
(у вас 3.0), фикс сам подбирает множитель отсчётов. Ctrl+PgUp / Ctrl+PgDn в игре: ±0.05. Режим
**Multiplier** — точный множитель X/Y вручную, как раньше. Ctrl+End — фикс вкл/выкл (сравнить с игрой).

Измерено в игре (камера в памяти, `tools/re/yaw_finder.ps1`, `read_rot.ps1`):

- MoH: поворот = **0.5 × MouseSensitivity единиц UE3 на отсчёт** (65536 = 360°), по горизонтали и
  вертикали одинаково, линейно (1000 отсчётов по 200 и по 2 за кадр — одинаковый поворот ±0.1%).
  `MouseSensitivity` = 35 по умолчанию (`MOHAInput.ini`, ползунок игры) → 0.0961° на отсчёт.
- MWR: `sensitivity × m_yaw` = 3 × 0.022 = **0.066° на отсчёт**.
- Множитель = 0.066 / (0.5 × 35 × 360/65536) = **0.6866**. Проверка: 1000 отсчётов → +12004 / +12024
  по Yaw и −12008 по Pitch при ожидаемых 12015 (= 66°).
- Если поменять чувствительность в меню игры, панель пересчитает множитель (читает `MOHAInput.ini`).
- Совпадает поворот на отсчёт (см/360 при том же DPI).

**Профиль одной кнопкой.** Панель → Profile → **MWR / CoD4**: чувствительность как в MWR (по числу из
MWR), вид как `cg_fov 65` (80.7° при 16:9), прицеливание (замедление и зум) как в MWR. **Game** возвращает
FOV и прицеливание игры (чувствительность не трогает). Справка: в MWR стандартный `cg_fov` — 65.
В одиночной игре MWR его не сохраняет (в `players2/config.cfg` его нет, значит 65), в мультиплеере
у вас тоже 65 (`config_mp.cfg`).

## Прицеливание (ПКМ) как в MWR

Замерено в обеих играх (поворот камеры на 1000 отсчётов, поля в памяти):

- **MoH** при прицеливании умножает мышь на постоянные **0.75** для любого зума (12022 → 9017 единиц, при
  FOV 70 и 80.7 одинаково) и сужает вид до FOV оружия, который от вашего FOV не зависит (коллиматор: 50°).
- **MWR** умножает на **tan(FOV / 2) / tan(cg_fov / 2)**, следуя за зумом (правило «0% monitor distance»).
  Замер: снайперский прицел M21 — 0.2067 = tan 7.5° / tan 32.5° (зум 15 при cg_fov 65). FOV прицела в MWR
  задан в градусах CoD (горизонталь 4:3): у винтовок 50.
- Поэтому при вашем FOV 80.7 коллиматор MoH (50°) давал зум сильнее, чем в MWR, а мышь замедлял меньше
  (×0.75 вместо ×0.549 по правилу MWR).

Панель → Sensitivity → Aiming down sights:

- **As MWR / CoD4** (по умолчанию): мышь умножается по правилу MWR от текущего FOV, плавно во время
  перехода. **Game** — ×0.75 игры. **Fixed multiplier** — свой постоянный множитель.
- **Aim zoom: As MWR** (по умолчанию): число FOV оружия читается как градусы CoD (4:3), как в MWR.
  Коллиматор 50 → 63.7° при 16:9 — та же картинка, что у винтовки в MWR. **Game** — FOV оружия как есть.
- Проверено в 4K: FOV прицела плавно уходит в 63.74°; поворот 12022 без прицела и 8807 с ним
  (×0.733, по формуле ×0.732 — как прицел винтовки в MWR, tan 25° / tan 32.5°).
- Данные зума игра заполняет при первом прицеливании в уровне; фикс находит их за ~0.25 с. Первое
  прицеливание после загрузки может пройти с замедлением игры. В каждом уровне свой солдат (свой класс
  объекта), фикс ищет заново после каждой загрузки (в строке лога `ADS: zoom block in object`).
- Ini: `[Mouse] AdsMode=mwr|game|custom`, `AdsMultiplier=0.75`, `AdsFov=mwr|game`. Ctrl+End (фикс выкл)
  отключает и замедление прицела фикса.

## Интерфейс в 4K

Масштабируется: меню, пауза, баннер задания, подсказки, патроны (Scaleform, `resolutionScale` = 3.0).
**Субтитры** игра рисует в пикселях для 720p (21 px): фикс находит эти размеры в объекте движка в памяти
и умножает на высоту/720 (в 4K — ×3, 65 px), сразу и в уже запущенном уровне. Панель: Display and game
settings → Subtitles (авто или свой множитель).

**Прицел** (4 штриха) игра рисует в пикселях 720p: у штрихов в `MOHAHUDCursor.DefaultCursorData` выключен
`bApplyScale`, хотя у остальных прицелов (красная точка, дробовик) он включён. Фикс включает его, и движок
масштабирует штрихи и разброс как на 720p. **Подписи над целями и напарниками** («Mother», «Voodoo») — это
rich text с размером шрифта 20 px; фикс умножает его на высоту/720. Шаблоны подписей правятся ещё в
главном меню, поэтому подписи, созданные в уровне, сразу получают нужный размер. Панель: Display and game
settings → HUD at high resolutions (прицел вкл/выкл, подписи авто или свой множитель).

Подсказки с клавишами: фикс переключает раскладку игры на английскую при запуске («WASD», а не «цфыв»);
выключается в панели или `[Startup] EnglishKeyboard=0`.

## Поле зрения (FOV)

Игра использует FOV 70° по горизонтали (`MOHAPlayerCamera.DefaultFOV`, как на консолях; в ini его нет).
Панель → Field of view: горизонтальные градусы или то же в единицах CoD4/MWR. Кнопки CoD 65 / 80 / 90:
при 16:9 это 80.7° / 96.4° / 106.3° в MoH. Значение применяется сразу, в том числе в уровне. Фикс меняет
DefaultFOV у шаблона камеры и у живой камеры. Камеры он находит через список объектов движка
(GObjObjects), поэтому после загрузки уровня новая камера получает FOV в течение секунды. Значение
меняется, только если там 70 или прошлое значение фикса, поэтому FOV техники и скриптовых сцен игра
ставит сама. Проверено в 4K: модель оружия не меняется. Поворот на отсчёт мыши от FOV не зависит:
при FOV 90 замер дал +12030 при ожидаемых 12015, так что «как в MWR 3» остаётся точным.
`[Display] FOV=0` — значение игры.

## Сглаживание

Своего рабочего AA в одиночной игре нет: галочка «Anti Alias» / `MaxMultisamples` в DX9 ничего не делает
(PCGamingWiki, TechSpot; в exe нет FXAA/MLAA). Лучший вариант — принудительное SGSSAA драйвера NVIDIA
через Profile Inspector (профиль с `moh.exe`):

| Параметр | Значение |
|---|---|
| Antialiasing – Compatibility (DX9) | `0x080000C1` (с ReShade-эффектами по глубине: `0x084000C1`) |
| Antialiasing – Mode | Override any application setting |
| Antialiasing – Setting | 2x [2x Multisample] (сейчас у вас; 4x качественнее, но тяжелее в 4K) |
| Antialiasing – Transparency Supersampling | 2x Sparse Grid Supersampling (столько же, сколько MSAA) |
| Antialiasing fix | On (иначе швы на оружии на фоне лучей света) |
| Texture filtering – LOD Bias (DX) | -0.5 для 2x (-1.0 для 4x), Driver Controlled LOD Bias = Off |

Это делает `MoH2010.NvProfile.exe` (ставится рядом с игрой). В панели: Display and game settings →
Anti-aliasing (NVIDIA driver), кнопки 4x / 2x / 8x SGSSAA и Undo. Утилита меняет только профиль драйвера
«Medal of Honor» (moh.exe), глобальный профиль не трогает. Прежние значения она сохраняет в
`MoH2010.NvProfile.backup.txt`, Undo и `uninstall.ps1` их возвращают. Запись профилей драйвера требует прав
администратора, поэтому Windows покажет запрос UAC. После этого игру нужно перезапустить. В профиле
драйвера «Medal of Honor» стоит флаг `Behavior Flags = 0x1` (Override считается как Application-controlled),
из-за которого ручной Override не работал; утилита его сбрасывает.
Из командной строки: `MoH2010.NvProfile.exe show | apply [--sgssaa 2|4|8] | restore`.
Сейчас стоит 2x MSAA + 2x SGSSAA: с 4x в 4K FPS заметно ниже; с 2x на уровне 240–270 FPS.

Меню ReShade на вкладке фикса раньше роняло игру с ~200 до 36 FPS (курсор дёргался). Причина: панель на
каждом кадре перебирала все режимы монитора (`EnumDisplaySettings`, сотни вызовов драйвера) и раз в
секунду перечитывала ini игры (MOHAInput.ini — 120 КБ). Теперь режимы кэшируются, а файлы читаются
только после изменения: с открытой панелью 250 FPS.

В игре оставить `MaxMultisamples=1`. Запасной вариант без драйвера — ReShade SMAA.fx. Не стоит:
`AllowD3D10=True` (одиночная игра — DX9), OGSSAA 4x4 в 4K, DXVK (конфликтует с ReShade и битами AA).
Источники: [PCGW](https://www.pcgamingwiki.com/wiki/Medal_of_Honor_(2010)),
[таблица AA-флагов NVIDIA](https://docs.google.com/spreadsheets/d/1ekUZsK2YXgd5XjjH1M7QkHIQgKO_i4bHCUdPeAd6OCo/pub),
[Guru3D: тест MrBonk](https://forums.guru3d.com/posts/4976580/),
[Guru3D: AA fix обязателен](https://forums.guru3d.com/threads/nvidia-anti-aliasing-guide-updated.357956/page-255#post-6043410).

## Запуск без окна CD-ключа

`tools\launch.ps1` запускает `moh.exe` напрямую с `SteamAppId=47790` (Steam должен быть запущен): проверка
Steam проходит, окна с ключом нет. Минус — Steam не считает время в игре.

## Установка

Нужны Visual Studio 2022 Build Tools (C++ x86) и CMake. Игра закрыта.

```powershell
.\tools\build.ps1 -Configuration Release   # сборка + тесты
.\tools\install.ps1                        # бэкап, копирование, ini
```

`install.ps1` кладёт в `Binaries\`: `dinput8.dll`, `MoH2010.PCFix.addon32`, `MoH2010.PCFix.ini`, а если
ReShade нет — `d3d9.dll` (ReShade 6.8.0 32-bit с аддонами, берётся из папки CoD4) и `ReShade.ini`
(меню на Home). Параметры: `-MaxFps 0` — не трогать ограничитель FPS, `-NoReShade`, `-NoIniTweaks`.
Всё заменённое сохраняется в `Binaries\MoH2010.PCFix.backup\<дата>\` с `install.json`.

Откат: `.\tools\uninstall.ps1` (или `-KeepReShade`).

Запускать **через Steam**: прямой запуск `moh.exe` даёт «Application load error 5:0000065434» (DRM).
Steam при каждом запуске показывает окно с CD-ключом — его нужно закрыть кнопкой.

## Проверка

1. `Binaries\MoH2010.PCFix.log`: строки `dinput8 CreateFileW import is hooked by … (SecuROM)`,
   `HID device opened past the CreateFile hook: \\?\hid#vid_1532&pid_0099&mi_03…`,
   `The game created its system mouse device`, `Mouse meter running`.
2. Игра доходит до интро EA и меню (без фикса — вечный сплэш).
3. Home → Add-ons → MoH 2010 PC Fix: *Polling rate ~1000 Hz*, *Game reads it with …*.
4. `tools\wait-and-check.ps1` — ждёт запуска из Steam и печатает итог + лог.

## Тесты

`ctest` (запускается в `build.ps1`):
- `unit_tests` — распознавание HID-путей, поиск слота импорта, масштабирование отсчётов без дрейфа,
  измеритель частоты;
- `proxy_in_game_process` — копия теста с именем `moh.exe`: ставит «SecuROM-перехват» в импорт
  `CreateFileW` настоящего `dinput8.dll`, создаёт DirectInput через прокси и проверяет, что ни одно
  HID-устройство не открылось через перехват (на этом ПК ~114 открытий в обход), перехват на месте после
  вызова, мышь обёрнута, измеритель запущен;
- `proxy_in_other_process` — в чужом процессе мышь не трогается.
